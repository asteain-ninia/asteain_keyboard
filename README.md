# asteain_keyboard
asteainの作成した、諸人工言語を統一的に扱うことのできる単一のフォントファイルと、入力を支援するキーボードです。
現在対応済みの文字は以下です：

- ASCII
- 幻字
- 新体アソーグ文字
- ザイロ文字
- デーレ文字
- 新笈霜文字

今後対応文字予定の文字は以下です：

- リパーシェ
- シャレイア文字
- 刻印体アソーグ文字
- キノン文字

キーボードのほか、ラテン文字転写された文書をこのフォントで表示ができるコードポイントへ転写する変換機が実装されています。
変換に対応している文字は以下です：

- 幻字
- デーレ文字
- ザイロ文字（仮設対応）

オンラインで利用するためのリンクはこちらです：
https://asteain-ninia.github.io/asteain_keyboard/
