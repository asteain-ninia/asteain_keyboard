# ローカル .fig ガイド追加実験

Figma APIを呼ばずに、保存済みの `.fig` を読み、既存のガイドを複製して別名保存する。
実行中に図面を外部へ送信しない。依存ライブラリの初回インストールだけネットワークが必要。

## 今回の出力

### お手本付き・下配置版

`../フォント作成_ラテン拡張お手本付き.fig`

- 「ラテン文字」ページの既存図面の下、ガイド x=0, y=862、お手本 x=0, y=801。
- ラテン1補助の文字62字を26・4・26・6升の4段で配置。
- 「追加ガイド（ラテン1補助）」と「お手本文字（ラテン1補助）」の2グループ。
- お手本は既存と同じMS Gothic、60px、白50%。1文字ごとに升の中央に配置。
- 各升とお手本のレイヤー名は文字とUnicode番号。
- 元ファイルから作り直すため、前回の右側のテストガイドは含まない。
- Windowsの `msgothic.ttc` とfontToolsから新規文字の表示キャッシュを生成。
  テキスト内容とキャッシュを共に保存し、既存のキャッシュは変更しない。
- 保存した.figから生成したローカルプレビューで配置を確認。Figmaへの再取り込み確認はユーザー側。

```powershell
node add-sample-guides.mjs '../フォント作成.fig' '../フォント作成_ラテン拡張お手本付き.fig'
node preview-sample-guides.mjs '../フォント作成_ラテン拡張お手本付き.fig' '../ラテン拡張ガイド確認.svg'
```

`font-samples.py` は既存のPython環境のfontToolsを使用する。
輪郭キャッシュの命令形式の参考:
[commandsBlobの復号実装](https://github.com/KwiTsukasa/figma-local-context-mcp/blob/main/FIG_DATA_STRUCTURE_ANALYSIS.md)。
プレビューはローカル検証用であり、Figmaアプリのスクリーンショットではない。

### 初回の読み書きテスト（ユーザーが取り込み成功を確認済み）

`../フォント作成_ローカルガイド追加テスト.fig`

- 「ラテン文字」ページの **x=1680, y=94** に「追加ガイド（ローカル編集テスト）」を追加。
- 元の大文字・小文字ガイドを各26升、計52升複製。色・升目・基準線・ロック状態を継承。
- 2段の行名は「追加・大文字用」「追加・小文字用」。文字のお手本や字形はまだ追加していない。
- 元ファイルは変更しない。出力先の上書きも拒否する。
- 検査結果は出力ファイルと同じ場所の `.fig.report.json` に保存。

元の31,971レイヤーに263レイヤーを追加。保存後の再読み込みで、元レイヤー・画像・
バイナリ部品・スキーマ・メタ情報が保たれていること、新規IDの重複や親の欠落がないこと、
入力ファイルのSHA-256が変化していないことを検査する。

**Figmaアプリでの取り込みは未検証。** ユーザーが取り込んで確認するための試作ファイル。
埋め込みサムネイルは元のままなので、ファイル一覧のプレビューには追加ガイドが写らない。

## 再実行（このディレクトリで）

Node.js 20、Python 3.12で動作確認。

```powershell
npm ci --ignore-scripts --no-audit --no-fund
python -m pip install --target .python-libs zstandard==0.25.0
node inspect.mjs '../フォント作成.fig'
node add-guide.mjs '../フォント作成.fig' '../フォント作成_別のテスト.fig'
```

このスクリプトは、この図面の「ラテン文字 → ガイド → 大文字・小文字」構成を対象にする。
汎用のFigma編集ソフトではない。文字ノードやコンポーネントの複製は対象外。

## ファイル形式と参考

ZIP内の `canvas.fig` は `fig-kiwi` ヘッダー・バージョン・圧縮スキーマ・圧縮メッセージを持つ。
ファイル内蔵のスキーマを用いて復号・符号化する。今回の版は106、スキーマがraw deflate、
メッセージがZstandard。書き出し時も元のヘッダーとスキーマを保ち、メッセージをZstandardで圧縮する。

- [Kiwi本家：スキーマとエンコーダー](https://github.com/evanw/kiwi)
- [ローカル.figのチャンク構造と復号例](https://github.com/sunyui/figma-parser/blob/main/scripts/decode_kiwi.cjs)

JavaScript側で復号・編集・検査し、PythonのZstandardで圧縮する。保存後は別実装のfzstdで
再び解凍して検査する。非圧縮のバイナリは符号化順序が変わる場合があるため、図面データの一致は
復号後の全フィールド比較で検証する。画像などcanvas以外のZIPエントリはバイト列で比較する。
